# Joan Guerrero Sanchez — Portfolio

Personal portfolio site in **Spanish and English**. Built with plain HTML, CSS, and JavaScript — no build step.

## What's included

- Bilingual content (ES / EN) with language toggle
- Two professional profiles, **Backend** and **AI / ML**, each with its own headline, skills, experience, projects and CV. Shareable links: `?profile=backend` / `?profile=ai`
- Ink-and-paper design inspired by the four elements (water, earth, fire, air)
- Projects with direct GitHub links
- Downloadable CVs (PDF, ES + EN, one per profile)
- Responsive layout

## Project structure

```
portfolio/
├── cv/               # Resume PDFs (Backend + IA, ES + EN)
├── index.html
├── styles.css
├── script.js
├── translations.js   # All text, links, and project data (per language + per profile)
└── README.md
```
