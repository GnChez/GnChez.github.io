# Joan Guerrero Sanchez — Portfolio

Personal portfolio site in **Spanish and English**. Built with plain HTML, CSS, and JavaScript — no build step.

**Live site:** [gnChez.github.io](https://gnChez.github.io)

## What's included

- Bilingual content (ES / EN) with language toggle
- Projects with direct GitHub links
- Downloadable CVs (PDF, ES + EN)
- Responsive layout and dark theme

## Project structure

```
portfolio/
├── assets/           # Profile photo
├── cv/               # Resume PDFs
├── index.html
├── styles.css
├── script.js
├── translations.js   # All text, links, and project data
└── README.md
```
